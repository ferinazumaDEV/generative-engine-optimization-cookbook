Why plain names confuse AI answer engines

A single word can name a dozen different things. When an answer engine reads Michael Jordan, does it mean the basketball player or the machine-learning professor at Berkeley? Apple could be the technology company or the fruit. Python is a programming language, a snake, and a comedy troupe. Amazon is a retailer and a river. Paris is a capital city, a town in Texas, and a first name.

A human reader disambiguates these from context. A machine building an answer has to guess — and a wrong guess pollutes the answer with the wrong entity. This page names the five entities but gives the machine nothing to pin them to.
