# Security policy

No code from this repository runs on anyone's machine except the scripts CI itself runs
(`scripts/`, `.github/workflows/`). What can go wrong here is a link that leads somewhere it
should not, a script that does something other than what it says, or a claim that misleads.

Report any of that **privately**, through
<https://github.com/ferinazumaDEV/generative-engine-optimization-cookbook/security/advisories/new>, not in a public issue. One
maintainer reads it; expect a best-effort answer, not a service level.

Supported: whatever is on `main`. Releases are archived on Zenodo as they were; an archived
release is not patched, the next one is.
