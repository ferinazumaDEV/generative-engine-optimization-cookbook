# Technical foundations of a crawlable website

A short reference on the specs and standards behind a machine-readable site.

<!-- claims:start -->

- The HTTP 200 status code indicates that a request has succeeded.
- The HTTP 404 status code indicates that the server cannot find the requested resource.
- The HTTP 301 status code indicates that a resource has moved permanently to a new URL.
- The Robots Exclusion Protocol, better known as robots.txt, was standardized as RFC 9309 in 2022.
- The Sitemaps XML format is defined by the sitemaps.org protocol, version 0.9.
- Schema.org is a shared structured-data vocabulary founded by Google, Microsoft, Yahoo and Yandex.
- The canonical link element tells search engines the preferred URL among duplicate pages.
- TLS 1.3, which secures modern HTTPS connections, is specified in RFC 8446.

<!-- claims:end -->

Each of the statements above is presented as fact, but a reader — human or machine — has no linkable path back to the authority that backs it up. To verify any of them you would have to leave the page and search.
