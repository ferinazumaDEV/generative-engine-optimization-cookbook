# Technical foundations of a crawlable website

A short reference on the specs and standards behind a machine-readable site.

<!-- claims:start -->

- The HTTP 200 status code indicates that a request has succeeded ([MDN — 200 OK](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status/200)).
- The HTTP 404 status code indicates that the server cannot find the requested resource ([MDN — 404 Not Found](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status/404)).
- The HTTP 301 status code indicates that a resource has moved permanently to a new URL ([MDN — 301 Moved Permanently](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status/301)).
- The Robots Exclusion Protocol, better known as robots.txt, was standardized as RFC 9309 in 2022 ([RFC 9309](https://www.rfc-editor.org/rfc/rfc9309)).
- The Sitemaps XML format is defined by the sitemaps.org protocol, version 0.9 ([sitemaps.org protocol](https://www.sitemaps.org/protocol.html)).
- Schema.org is a shared structured-data vocabulary founded by Google, Microsoft, Yahoo and Yandex ([schema.org — About](https://schema.org/docs/about.html)).
- The canonical link element tells search engines the preferred URL among duplicate pages ([Google Search Central — canonicalization](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls)).
- TLS 1.3, which secures modern HTTPS connections, is specified in RFC 8446 ([RFC 8446](https://www.rfc-editor.org/rfc/rfc8446)).

<!-- claims:end -->
